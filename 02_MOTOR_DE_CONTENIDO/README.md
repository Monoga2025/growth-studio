# 02_MOTOR_DE_CONTENIDO

Content engine: Python and JavaScript scripts that generate, compile and deliver short-video scripts.

- Generators: `viral_script_generator.py`, `youtube_consulting_script_generator.py`, `daily_growth_engine.py`, `run_daily_content.py`.
- Teleprompter: `teleprompter_compiler.py`, `teleprompter_engine.js`, `build_exact_teleprompter.js`.
- Delivery: `telegram_listener.py`, `telegram_video_bot.js`, `twenty_card_sync.py` (CRM cards).
- Inputs: `apify_miner.py`, `transcribe_audio.py`, `shared_context.py` (read-only business context).
- Tests: `test_content_engine.py`, `test_teleprompter.js`.
