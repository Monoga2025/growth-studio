# 01_GENERADOR_LOTES_LA

Node scripts that build demo websites for local businesses and print QR cards.

- `apify_google_maps_scraper.js`: Apify integration that pulls business data (name, address, phone, rating, photos) from Google Maps.
- `demo_builder.js`, `build_batch_bucaramanga.js`, `build_demo_masterpro.js`, `generate_la_batch.js`: batch demo builders.
- `codex_web_builder.js` and `mobile_app_builder.js`: site and app templates; `fetch_photos.js` downloads business photos.
- Generated output was not kept in this copy.
